## Stack

- **Framework** : Next.js 16 + React 19 (App Router, React Server Components)
- **Mobile** : React Native / Expo
- **Styling** : Tailwind CSS v4
- **State UI** : [React Zero UI](https://github.com/react-zero-ui/core) — zéro re-render pour les animations complexes
- **Animations** : Motion (Framer Motion)
- **Backend** : Node.js, Express, Prisma, Supabase (PostgreSQL)
- **Tests** : Playwright
- **Analytics** : Vercel Analytics

## Lancer le projet

**Prérequis :** Node.js 18+

```bash
npm install
npm run dev        # dev → localhost:3000
npm run build      # build production
npm run start      # serveur production
npm run test       # tests Playwright
```

---

## Déployer sur Vercel

1. Push le repo sur GitHub
2. [vercel.com](https://vercel.com) → New Project → importer le repo
3. Vercel détecte automatiquement Next.js — aucune config à changer
4. Cliquer **Deploy**

Chaque push sur `main` redéploie automatiquement.
